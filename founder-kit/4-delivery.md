# Delivery — the 30-day board

One Notion page per client. Copy this checklist verbatim, tick in order. Every deliverable passes three gates: **evidence check** (every claim traceable to the transcript or their email) → **founder read-aloud pass** → **client written OK**. Two revision rounds, that's it.

## Week 1 — story
- [ ] Story session held + transcript saved
- [ ] Intake email answers filed (this is the evidence locker)
- [ ] 3 angle memos sent (Day 3)
- [ ] Angle approved by client (Day 5)
- [ ] Release facts doc confirmed

## Week 2 — drafts
- [ ] Feature drafted — Claude-drafted from transcript, founder-edited for voice, every claim evidence-checked
- [ ] Feature to client — revision round 1
- [ ] Press release drafted + client approved (one round)
- [ ] Release distributed via wire → syndication URLs logged
- [ ] Report to client uses the honest phrasing: **"distributed via X, syndicated to N pages"** — never "featured in"

## Week 3 — submission
- [ ] Feature revision round 2 → client final OK in writing
- [ ] Submitted to outlet programme
- [ ] Bios (25/100/250), positioning one-pager, press-page copy drafted

## Week 4 — live
- [ ] Feature published → URL + disclosure status logged
  - *If the outlet's schedule slips past Day 30: client informed same day with the new date. This is the only acceptable slip, and it's theirs to know first.*
- [ ] LinkedIn profile rewrite delivered
- [ ] Amplification kit: 3 posts, banner, badge rules ("Featured in" = the editorial feature only)
- [ ] Closeout call: walk everything, ask for the testimonial + case-study OK (founding clients agreed to this at purchase)
- [ ] Ask: "who are two founders you know who need this?" → CRM as `To contact`, Source: `Referral`

## Tool stack (all free)
Claude (drafting) · Google Meet + transcript (interviews) · Notion (CRM + client boards) · Stripe payment links / bank transfer (getting paid) · GitHub Pages (the site).
