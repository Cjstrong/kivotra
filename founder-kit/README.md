## The weekly ritual (4 hours, non-negotiable)

Monday: 10 named founders into the CRM → Tue–Thu: manual snapshots + emails → calls as they book → proposal + payment link same day as every call. 10 snapshots → ~2 calls → ~1 close per fortnight. **If 40 snapshots produce 0 closes, change the offer, not the effort.**

## Deploying the site (free, 5 minutes)

Push this repo, then either point Vercel at `founder-kit/site/`, or enable GitHub Pages on the repo and serve that folder. Before it goes live, replace the two `TODO` spots in `index.html` (email address / booking link). The brand-film site stays untouched — this page can live at a subdomain (e.g. `start.kivotra.com`) until the film ships.
